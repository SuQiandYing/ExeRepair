## 维护约定

- 按功能、输入、处理步骤、输出和错误说明接口。
- 使用 `TARGET.exe`、`OUTPUT.exe` 等示例名，不列举目标程序或分发平台。
- 配置参数保留在代码中；用户说明不复制目标摘要、固定偏移或个别输入名单。
- 格式与字节保护检查以实际接口为准；描述方式不改变校验规则。
- 验证记录与使用说明分开保存，不将个人电脑路径写入项目 Markdown。
- 更新接口文档时同步检查相对链接、目录覆盖及示例参数。
