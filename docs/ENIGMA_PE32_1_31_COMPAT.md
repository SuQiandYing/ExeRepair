# PE32 Enigma 1.31 动态基址兼容记录

本记录描述一组通过完整输入 SHA-256 和长度识别的 PE32 Enigma 1.31 兼容边界，文件名不参与选择。
工具生成独立输出，并保留原始输入、二进制差异、验证报告和回滚脚本。

## 运行时适配

载荷描述符从门控副本的实际引擎基址计算。适配器检查调度入口、全局表、谓词/真值表项、
KSA/PRGA 原生调用记录和目标寻址类型，然后才挂接调度入口。捕获过程只拥有自己的探测进程，
上下文通过一次 RPC 返回 Python 内存；7 个描述符中只有 5 个非空载荷进入后续校验，硬件分量
保持关闭，密钥长度为 32。捕获失败或超时会清理探测进程，不会发布修复文件。

## 构建验证

修复构建会：

1. 用精确谓词记录和已有真值记录验证门控编辑；该配置不假设存在 dialog 分支。
2. 用每个载荷的 CRC32/SHA-256 检查恢复字节，并将恢复复制 helper 放入新 PE 节。
3. 校验 BCJ 往返、引擎重新提取和完整 `seep.binary-patch.v2` 补丁重放。
4. 保持原始密文载荷不变，不写入激活分量或注册表。

复用清单时，工具仍会重新读取文件并校验身份、顺序、范围、CRC32 和 SHA-256。清单和
搜索游标使用相对文件名，源码不包含机器相关的绝对路径。

## 回归范围

自动流程在 Windows x64 上完成隔离捕获、OpenCL 搜索和 5 个载荷恢复。独立无注入观察覆盖
启动选项到主窗口的流程；这不等同于完整剧情、所有存档或全部资源的长时间测试。
